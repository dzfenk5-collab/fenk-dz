# FENK DZ

واجهة أولية Responsive لشحن الألعاب، مبنية من الصفر وفق المرجع البصري المرسل.

## الحالة الحالية
- RTL Arabic
- Mobile-first responsive layout
- اختيار الألعاب والباقات
- Player ID
- بريد موب فقط كطريقة الدفع المعروضة
- رفع صورة إثبات الدفع (واجهة)
- نافذة تأكيد الطلب
- لا يوجد اتصال فعلي بـ Supabase بعد

## الخطوة التالية
ربط Supabase: الألعاب، الباقات، الطلبات، إثباتات الدفع، المستخدمون، ولوحة الإدارة.
